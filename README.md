# DO's website

My personal portfolio for IT support and cybersecurity opportunities.

[Visit my portfolio](https://davidswrldzx.github.io/)

## About the project

I wanted one place where people could learn about me, view my projects, and get in touch. The site brings together my background, technical skills, and work documented on GitHub.

## My role

I chose the content and design direction, including the black background, larger text, project selection, hover effects, and contact options. I reviewed the site and requested changes to keep it clean and easy to use.

I used ChatGPT to help write and refine the HTML, CSS, and JavaScript. I have an HTML background, and I am still learning the JavaScript used in this project.

## Features

- A clean black theme with readable text
- A layout that adjusts to phones, tablets, and desktops
- Three featured projects and a link to my other GitHub repositories
- Project details that open when selected
- Hover effects and navigation that highlights the current section
- Direct email, LinkedIn, and a copy email button
- The tab title DO's website and an O7 icon

## Tools used

- HTML for the page structure and content
- CSS for the layout, colors, spacing, and hover effects
- JavaScript for navigation highlights and the copy email button
- GitHub Pages for hosting

The project details use HTML's built in `details` and `summary` elements.

## Project files

| File | Purpose |
| --- | --- |
| `index.html` | Page content, links, and structure |
| `styles.css` | Styling and responsive layouts |
| `script.js` | Navigation highlights, email copying, and the copyright year |
| `.nojekyll` | Serves the static website directly on GitHub Pages |

## Run locally

Open a terminal in the project folder and run:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Hosting

The website is published through GitHub Pages from the `main` branch and the repository root.
