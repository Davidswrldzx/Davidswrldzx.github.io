# DO's website

My personal portfolio for IT support and cybersecurity opportunities.

The website includes a short introduction, three featured projects, links to the rest of my GitHub work, and contact options.

Built with HTML, CSS, and JavaScript. No build step is needed. The browser tab title is DO's website and the icon displays O7.

## Hosting

GitHub Pages serves the site from the main branch and the repository root. The .nojekyll file allows the static files to be served directly.

## Local preview

Run `python3 -m http.server 8000` from this folder, then open `http://localhost:8000`.
